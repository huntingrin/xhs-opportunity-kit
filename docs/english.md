# English quick start

XHS Opportunity Kit is a local-first business SDK for collecting, reviewing and tracking Xiaohongshu opportunities. It is not an official platform SDK and does not include login credentials, a browser, an LLM or messaging automation.

Requires Node.js >=22.13. The agent skill ships dependency-inlined entry points that need no install step:

```sh
node skills/xhs-opportunity-kit/scripts/xhs-opportunity.mjs doctor
node skills/xhs-opportunity-kit/scripts/xhs-opportunity-mcp.mjs --db /absolute/path/to/opportunities.sqlite
```

Or install the compiled GitHub release. npm 12 refuses remote tarball URLs by default (`allow-remote` is `none`, reported as `EALLOWREMOTE`), so download it first:

```sh
curl -L -o huntingrin-xhs-opportunity-kit-0.1.0.tgz \
  https://github.com/huntingrin/xhs-opportunity-kit/releases/download/v0.1.0/huntingrin-xhs-opportunity-kit-0.1.0.tgz
npm install -g ./huntingrin-xhs-opportunity-kit-0.1.0.tgz
xhs-opportunity --help
```

Release archives contain the compiled `dist/`, so a blocked install script does not affect them.

Use the JSON CLI from any tool-enabled Agent, the standard stdio MCP server from an MCP-capable host, or the typed SDK in Node. The optional Skill is a workflow guide, not a vendor-specific runtime dependency. An Agent with no code/tool execution cannot run this package by itself.

Clone the repository and run `npm ci && npm test` to develop. `node examples/quickstart.mjs` runs a synthetic, offline end-to-end example in a temporary database.

Collect/import notes, inspect evidence IDs and readable quotes, record an evidence-backed review with work mode, demand type, rate and risk flags, screen unknown facts conservatively, and export JSON/CSV or a static HTML report. A synthetic `demo` report lets you inspect the output without touching the database. Real platform access requires a separately configured MCP provider or notes supplied by the host. Search coverage and partial failures are explicit. No messaging, scheduling or publishing is performed.

Read [CLI](cli.md), [SDK](api.md) and [providers](providers.md) for contracts. Data is stored outside the package by default. Do not commit real leads, messages, accounts or provider credentials. `skills/xhs-opportunity-kit/scripts/` and `THIRD-PARTY.md` are generated by `npm run bundle:skill` and committed on purpose; regenerate them after changing `src/` (`npm run check:bundle` verifies they are in sync).
